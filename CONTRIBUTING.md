# Contributing to the PulseEngine Beta

Thank you for helping validate PulseEngine.

The public repository is primarily for **testing, feedback, documentation and issue reporting**. The proprietary engine implementation is developed privately, so engine-source pull requests are not part of the beta contribution model.

## Best ways to contribute

1. Run PulseEngine on a real React + Vite repository you are authorized to test.
2. Submit a **Beta feedback** issue, including negative results.
3. Report reproducible installation/runtime bugs with sanitized logs.
4. Suggest missing workflows or commonly unsupported opportunity shapes.
5. Improve public documentation through a pull request.

## High-value feedback

We especially want cases where:

- PulseEngine proposes the wrong journey boundary;
- PulseEngine misses an obvious later-journey cost;
- a KEEP should have been REJECT;
- a REJECT should have been KEEP;
- UNSUPPORTED represents a common real-world pattern;
- setup is confusing enough that you would uninstall;
- the review evidence is insufficient for a teammate to approve the patch.

## Please protect your organization

Do not commit or post:

- proprietary application source;
- secrets or credentials;
- customer data;
- private repository URLs;
- internal hostnames;
- confidential architecture diagrams.

If a bug cannot be explained safely in public, use a private contact route rather than sanitizing poorly.
