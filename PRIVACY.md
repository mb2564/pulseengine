# Privacy and Repository Data

PulseEngine is intended to be evaluated on repositories the tester controls.

For public feedback:

- do not paste proprietary source code;
- do not paste secrets, credentials or tokens;
- do not paste customer data;
- do not paste private repository URLs or internal infrastructure details unless you intentionally want them public.

For product validation, we generally need only:

- PulseEngine version/build
- outcome class
- measured delta
- review flags
- whether the developer agreed with the candidate
- setup friction
- qualitative adoption feedback

A scrubbed review summary is normally sufficient. Source code is not required for feedback unless the tester explicitly chooses to share it.
