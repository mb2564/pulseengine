# Support

For the public beta:

- use **Beta feedback** for completed evaluation runs;
- use **Bug report** when PulseEngine fails unexpectedly;
- use **Feature request** for missing workflows or framework support.

Before opening an issue, please remove proprietary code, secrets, customer data and private URLs.

When reporting an error, include:

- operating system;
- Node.js version;
- PulseEngine version/build;
- command that failed;
- sanitized error text;
- whether the repository is React + Vite;
- whether the failure reproduces on a clean Git working tree.

Do not upload a private repository unless you deliberately choose to share it.
