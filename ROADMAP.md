# Public Beta Roadmap

The roadmap is evidence-driven. Items move forward only if external repository testing supports them.

## Now

- make installation self-serve;
- validate candidate quality on independent React + Vite repositories;
- validate the isolated experiment/review workflow;
- collect false-positive, false-negative and unsupported-shape cases;
- learn whether developers would keep PulseEngine installed.

## Next, if validated

- improve common unsupported boundary shapes;
- reduce configuration friction;
- harden CI/PR workflows;
- improve cross-repository evidence comparability;
- make review output easier for teams, not only individual developers.

## Later, only if commercial demand is real

Potential productization directions include:

- hosted/GitHub App execution for stronger IP isolation;
- organization-level policy and governance;
- portfolio/repository-level opportunity tracking;
- commercial licensing and team administration.

We are intentionally not building a dashboard, billing system or broad framework matrix before the core developer value is proven.
